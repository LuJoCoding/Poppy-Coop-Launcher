POPPY PLAYTIME CO-OP - LAUNCHER 1.3.3 (with Chapter 2)
=====================================================

Unofficial version of the PoppyCoop Launcher 2.0 (fan mod, not by Mob Entertainment).
New compared to the original:
- Chapter 2 is playable in the launcher (beta).
- Real player figures in Chapter 2: full-body figure with GrabPack (backpack, launchers, hands),
  animations for standing, walking, running, crouching, jumping; launched hands fly with a black
  cable to where your friend actually shoots; the green hand is shown green on the figure.
- The green hand is shared: if one player has it, everyone gets it.
- Doors, floor hatches, levers, crane handles, vents, spider webs, wooden walls, cut-outs, carts etc.
  move for your friend exactly as for you and stay that way after a reload.
- Puzzle pieces (furnace doors, gears, molds, paint cartridges, garage levers) are shared.
- Power, switches, keys, items and checkpoints are shared
  ("Load Game" brings everyone to the furthest checkpoint).
- For 2, 3 or more players: everyone joins the same room.
- F6: teleport to another player (with several players each press goes to the next one).
  Keys can be changed in ue4ss/Mods/PoppyCoop/keybinds.txt (F8/F9 stay free for other mods).
- Crash when reloading a checkpoint fixed.
- The launcher runs much more smoothly.

Installation (Windows)
----------------------
1. Unzip, start PoppyCoopLauncher.exe.
   Windows may show "Windows protected your PC" (the exe is not signed):
   "More info" -> "Run anyway".
2. First start: choose the game folder, set name and colour, install the mod.
   Chapter 2: click "Chapter 2" on the left. The launcher usually finds the folder itself, otherwise
   Steam -> right-click "Poppy Playtime - Chapter 2" -> Manage -> Browse local files.
3. If you used an older version: just start this one and press PLAY,
   the mod is updated to 1.3.3 automatically.

Playing together
----------------
- One player presses "Create Game" and shares the room code, everyone else presses "Join Game" and enters it.
- Everyone loads the SAME checkpoint in the game (Play -> Load Game).
- Everyone needs this launcher version (1.3.3), otherwise the mods don't match.
- Firewall prompt for PoppyCoopNet.exe: "Allow".
- F6 = teleport to another player (cycles), F7 = buddy figure, O/P = record/replay your movement.
- Checkpoints only move forward: a player who is behind doesn't reset the others.
- Only share the room code with people you want to play with.
- In game, press F10 and type "coop_status" to see the room and players.
